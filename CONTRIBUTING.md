# Contributing to PyBgWorker

First of all, thank you for considering contributing to **PyBgWorker** 🙌  
Contributions of all kinds are welcome — code, documentation, tests, ideas.

---

## 🧱 Project Philosophy

PyBgWorker aims to be:
- Simple
- Reliable
- Easy to understand
- Minimal in dependencies

Please keep this philosophy in mind when contributing.
